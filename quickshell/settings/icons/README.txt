SVG icon overrides for the Settings category list.
Drop a WHITE, single-colour SVG here named after the category key and it replaces the built-in glyph:

  accessibility.svg  network.svg  users.svg  system.svg  storage.svg
  sound.svg  screen.svg  accessories.svg  notifications.svg  captures.svg

Missing file = the Nerd Font glyph is used. Restart the shell (viii restart) after adding files.
